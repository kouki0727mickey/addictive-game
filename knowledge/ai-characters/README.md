# AIキャラクター・会話NPC（重点領域）

> English edition: [../en/ai-characters/](../en/ai-characters/README.md)

このナレッジベースが「世界一」を最初に取りにいく領域。
対象は、**LLMで会話し、記憶を持ち、プレイヤーと関係を築くキャラクター**全般
（ゲームNPC、AIコンパニオン、AI VTuber、公式IPキャラのAI化）。

## なぜここに集中するか
1. **最も変化が大きい**: AIがなければ成立しない体験の代表（→ [ai-native-entertainment](../foundations/ai-native-entertainment.md)）
2. **知見が散らばっている**: ゲームAI研究、コンパニオンアプリ、配信文化、規制がバラバラに語られている
3. **日本に強みがある**: キャラクター文化、VTuber、声優、そして声の権利に関する法務省の解釈指針（2026年8月）
4. **規制が体験設計を直接決める段階に入った**: 会話の範囲ひとつで法的な分類が変わる（→ [patterns](patterns.md) P01）

## 最重要の5原則（パターン集の要約）
1. **会話範囲を最初に決める**: 体験・コスト・法的分類がすべてここから決まる（P01）
2. **事実とルールはエンジンが持つ**: LLMの「言ったこと」をゲームの真実にしない（P16）
3. **判定はキャラ本人にさせない**: 説得の成否などは別の判定器で決める（P17）
4. **関係性は数値の状態として持つ**: 好感度をLLMの気分に任せない（P11）
5. **終わり方を設計する**: 無限に続く会話は、健全性でも規制でも弱点になる（P22）
