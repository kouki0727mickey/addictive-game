# アニメ・マンガ × AI

## 一言で言うと
日本の最強IP領域。現場の人手不足は深刻で、AIへの期待は大きい一方、
**作画・画風が作品価値の核** なので、クリエイターとファンの反発リスクも最大級。
勝ち筋は「作家性の置き換え」ではなく **「作家性を守ったまま周辺工程を軽くする」** こと。

## アニメ制作工程とAI

| 工程 | AI活用の方向性 | 作家性への影響 |
|---|---|---|
| 企画・シナリオ | 設定整理、資料検索 | 小 |
| 絵コンテ | ラフのビジュアル化補助 | 中 |
| 原画 | （核心工程。置き換えへの反発が最も強い） | 大 |
| 動画（中割り） | 中割り生成・補間の支援 | 中 |
| 仕上げ（彩色） | 自動彩色・色指定の補助 | 小〜中 |
| 背景 | 写真・3Dからの背景起こし、美術ボードからの展開 | 中 |
| 撮影・コンポジット | エフェクト、合成の効率化 | 小 |
| 翻訳・字幕 | 多言語同時配信 | 小 |

## マンガ

- **翻訳**: 海外同時配信と海賊版対策の両面で、機械翻訳 + 人の監修が最も効果の大きい用途
- **制作補助**: 背景、トーン、ベタ、下書きからの清書補助
- **ネーム・プロット**: 編集者との壁打ち用途
- **読者側**: 縦読み（ウェブトゥーン）への再構成、多言語化

## 論点
- **画風の模倣**: 特定の作家の画風に寄せた生成・LoRAへの強い反発。法的にも「画風」自体は保護されにくいが、
  日本の文化庁の考え方では、特定作家の作品を意図的に模倣する目的の学習は第30条の4の適用外となり得るとされる → [ethics-legal](../ethics-legal/ethics-legal.md)
- **ファンの受容**: 「AI使用」が炎上の引き金になるケースが繰り返し起きている。開示方針を先に決める
- **労働環境**: 低賃金・長時間の工程をAIが軽くできるなら、それは業界全体の利益になり得る

## 💡仮説
- 最も価値が大きいのは **「翻訳・ローカライズによるグローバル同時展開」** と **「自社IPの権利処理済みモデルによる周辺展開（ゲーム・グッズ・キャラ対話）」**
- 「公式が許諾した、キャラと話せる体験」は、ファンの反発が少なく収益化しやすい
