# 「ハマる」の科学とAI — エンゲージメント設計

> このリポジトリの核となる記事。

## 一言で言うと
人がハマる体験は **「欲求（動機）× ループ（構造）× 調整（個別化）」** で成り立つ。
AIは3つ目の「調整」を桁違いに強くする。だからこそ、**健全なハマり（没入・成長・つながり）** と
**不健全なハマり（強迫・損失回避・時間の搾取）** を設計段階で区別する必要がある。

## 1. 動機の理論（なぜハマるのか）

| 理論 | 要点 | 設計への示唆 |
|---|---|---|
| 自己決定理論（SDT） | 自律性・有能感・関係性の3欲求が満たされると内発的に続ける | 選択肢、成長実感、仲間の存在を用意する |
| フロー理論 | 挑戦と能力が釣り合うと没入する | 難易度をスキルに追従させる |
| 変動報酬（強化スケジュール） | 予測できない報酬は行動を強く維持させる | 強力だが強迫的になりやすい。使い方に倫理が要る |
| 好奇心・情報ギャップ | 知りたい欠落があると埋めたくなる | 謎、未踏の地図、次回予告 |
| ツァイガルニク効果 | 未完了のタスクは記憶に残る | 進捗バー、あと少しの演出 |
| 社会的比較・互恵性 | 他者との比較、お返しの義務感 | ランキング、ギフト。過度だと圧力になる |
| 保有効果・損失回避 | 持っているものを失いたくない | ログインボーナス途切れ等。不健全化しやすい |

## 2. ループ構造（どう続くのか）

- **コアループ**（秒〜分）: 行動 → フィードバック → 報酬（例: 撃つ→当たる→倒す）
- **メタループ**（時間〜日）: 報酬 → 成長/収集 → より大きな挑戦
- **ソーシャルループ**（日〜月）: 共有 → 反応 → 帰属意識
- **ライブループ**（週〜年）: イベント → 新コンテンツ → 再訪

良いゲームは、コアループ単体で「触っているだけで気持ちいい」。
メタループで無理やり引き延ばしているゲームは、報酬を外すと崩れる。

## 3. AIが強化するもの

| 対象 | 従来 | AIで何が変わるか |
|---|---|---|
| 難易度 | 固定 or 簡単なルールで調整 | プレイヤーモデルに基づく連続的な動的難易度調整（DDA） |
| コンテンツ供給 | 開発チームの制作速度が上限 | 生成により「飽き」の到来を遅らせる。ただし品質管理が課題 |
| 関係性 | NPCは定型セリフ | 記憶を持ち、プレイヤーを覚えているキャラクター |
| 物語 | 事前に書かれた分岐 | プレイヤーの行動から生まれる物語 |
| LiveOps | 全員に同じイベント | セグメント別・個人別のイベント、オファー、通知 |
| 離脱予測 | 事後分析 | 離脱の兆候を検知して介入 |

## 4. 健全 vs 不健全 の判定フレーム

AIによる個別化は、プレイヤーの弱点を突くことにも使えてしまう。以下で自己点検する。

| 問い | 健全 | 不健全 |
|---|---|---|
| やめた後にどう感じるか | 満足・また遊びたい | 後悔・時間を失った感覚 |
| 動機の源 | 楽しい、上達したい、会いたい | 失いたくない、取り残されたくない |
| 個別化の目的 | 体験の質（ちょうどいい難易度・好みの物語） | 支出や滞在時間の最大化のみ |
| 個別化の対象 | ゲームプレイ | 価格・課金オファー（特に脆弱な層への） |
| 透明性 | プレイヤーが仕組みを知っても楽しめる | 知られたら困る |
| 終わり方 | 区切り・自然な休憩点がある | 終わりがなく、やめる理由を奪う |

### レッドライン（やらない）
- 未成年・依存傾向が見られるユーザーへの課金オファーの個別化最適化
- AIキャラクターが孤独や罪悪感を利用して課金・滞在を促す設計
- 確率・価値の実態を個人ごとに不透明に変える設計
- 休憩・退出を妨げるダークパターン

### グリーンパターン（積極的にやる）
- 長時間プレイ時の自然な区切りの提示
- 「上達」を可視化する（有能感）
- 他者と協力・共有する理由を作る（関係性）
- AIキャラクターの記憶・関係性を**プレイヤーが管理できる**ようにする

## 5. 指標設計

滞在時間とARPUだけを最適化するとAIは不健全な方向へ最適化する。
**目的関数に「体験の質」を入れる**ことが最重要。

| 種類 | 指標例 |
|---|---|
| 継続 | D1/D7/D30リテンション、セッション頻度 |
| 質 | 自発的な再訪率（通知経由でない）、プレイ後満足度アンケート、推奨意向 |
| 健全性 | 深夜長時間プレイ率、課金後の返金・後悔率、自己制限機能の利用率 |
| 収益 | ARPDAU、LTV（ただし健全性指標とセットで見る） |

💡仮説: 「通知なしでの自発的再訪率」は、健全なハマりを測る最も優れた単一指標。

## 6. 実践チェックリスト
- [ ] コアループは報酬を外しても触って楽しいか
- [ ] AIによる個別化の対象を「体験」と「価格」で分け、後者に制限を設けたか
- [ ] 目的関数・KPIに健全性指標を入れたか
- [ ] AIキャラクターの発言に「課金・滞在の誘導禁止」のガードレールを入れたか
- [ ] 年齢・脆弱性に配慮した例外ルールがあるか
- [ ] 仕組みをプレイヤーに説明できるか
