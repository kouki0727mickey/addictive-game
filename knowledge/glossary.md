# 用語集

| 用語 | 説明 |
|---|---|
| ARPU / ARPDAU | ユーザー1人あたり（1日あたり）の平均売上 |
| DDA（Dynamic Difficulty Adjustment） | 動的難易度調整。プレイヤーの状況に応じて難易度を変える |
| FSM（有限状態機械） | 状態と遷移で振る舞いを記述する古典的なゲームAI手法 |
| GOAP（Goal-Oriented Action Planning） | 目標から逆算して行動列を計画するゲームAI手法 |
| LiveOps | リリース後の継続運営（イベント、アップデート、分析） |
| LLM | 大規模言語モデル。テキストの理解と生成を行う |
| LoRA | 大きなモデルに少量の追加パラメータを学習させる軽量ファインチューニング手法 |
| LTV | 顧客生涯価値。1ユーザーが利用期間全体でもたらす売上 |
| NPC | ノンプレイヤーキャラクター。プレイヤーが操作しないキャラ |
| PCG（Procedural Content Generation） | 手続き型コンテンツ生成。アルゴリズムでマップ等を生成する |
| RAG | 検索拡張生成。外部の資料を検索してLLMに渡し、回答の正確さ・一貫性を高める |
| SDT（自己決定理論） | 自律性・有能感・関係性を内発的動機の源とする心理学理論 |
| TTS | テキスト読み上げ（音声合成） |
| WFC（Wave Function Collapse） | 局所的な制約を満たすようにタイルを配置する生成アルゴリズム |
| ストーリーレット | 条件付きの短い物語断片。状況に応じて選ばれる |
| ダークパターン | ユーザーを意図しない行動へ誘導するUI・設計 |
| ドラマ・マネージャー | 物語の進行を監視し、面白さのためにイベントを調整するシステム |
| ビヘイビアツリー | 行動を木構造で組み合わせるゲームAI手法 |
| プロンプトインジェクション | 入力文で指示を上書きし、AIに想定外の挙動をさせる攻撃 |
| ワールドモデル | 環境の状態と行動から次の状態（映像）を予測・生成するモデル |
| 3D Gaussian Splatting | 3D空間をガウス分布の集合で表現し、高速に描画する手法 |
