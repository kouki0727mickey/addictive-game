# ORBIT SWITCH

タップだけで遊べる、つい「もう一回」を押してしまうワンタップゲーム。

プレイヤーは中心の周りを回り続けます。**タップ（またはスペースキー）で内側 ⇄ 外側のリングを切り替え**、トゲをよけながらジェムを集めましょう。

画面は**日本語と英語**に対応しています。ブラウザ/端末の言語が日本語なら日本語、それ以外は英語で表示され、メニューの EN / JA ボタンでも切り替えられます。翻訳は `js/i18n.js` にまとまっています。

## 遊び方

| 操作 | 内容 |
|------|------|
| タップ / Space / ↑ / ↓ | リングを切り替え |
| Esc / P | 一時停止・再開 |
| メニュー・結果画面の空白をタップ | すぐにスタート / リトライ |

- **トゲ**を1つ通過するごとに +1 点
- **ジェム**を取るとコンボが増え、5コンボごとに倍率アップ（最大 ×5）
- ジェムを **10 個連続**で取ると **FEVER!!**：4 秒間スコア 2 倍、トゲを粉砕できる
- トゲをギリギリで回避すると **CLOSE!**（ニアミスボーナス）
- 進むほど速くなり、終盤はジグザグ配置でリズム感が試されます

## 「もう一回」を生む仕掛け

- 1 プレイ数十秒、死んだら即リトライ（空白タップでもOK）
- ベストまでの残り点数を表示（「おしい！あと 2 点」）
- 3 つ並行のミッション、コインでスキン解放、レベル、デイリーボーナス（連続ログインで増加）
- 結果画面に「次のスキンまであと 🪙N」
- 音程がフィーバーに近づくほど上がるジェム音、ヒットストップ・スローモーション・振動などの手触り
- メニュー背後でオートパイロットがデモプレイ

## 起動

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで遊べます。

オフライン対応（Service Worker）や PWA として使う場合は HTTP で配信してください。

```sh
npm start          # http://localhost:8080
```

## 開発

```sh
npm install
npm run lint       # ESLint
npm test           # ユニットテスト + 公平性テスト（node:test）
npm run e2e        # Playwright でスマホ/PC/横向き/オートプレイ/オフラインを検証しスクショ保存
```

### 構成

| ファイル | 役割 |
|----------|------|
| `js/core.js` | ゲームシミュレーション（DOM 非依存・シード付き乱数で決定的）。ブラウザと Node の両方で動作 |
| `js/meta.js` | コイン・スキン・ミッション・レベル・デイリーボーナス・セーブの検証 |
| `js/audio.js` | WebAudio による効果音（音声ファイルなし） |
| `js/main.js` | 描画・入力・画面遷移 |
| `sw.js` | オフライン用 Service Worker |
| `tests/bot.js` | 公平性検証用のオートパイロット（完璧ボット / 反応遅延とタイミング誤差を持つ人間ボット） |

### 公平性の担保

レベル生成は「リングを切り替えなければ避けられないトゲ同士の間隔」を必ず反応時間以上に保ちます。テストでは

- 完璧ボットが 100 シードすべてで 90 秒以上生存すること
- 反応 200ms・誤差 ±60ms の人間ボットが序盤 30 秒を 95% 以上生存すること
- どのオブジェクトもスポーン地平線より先に実体化しない（1 周先に置かれて現在位置と重なる「見えない壁」がない）こと

を確認しています。
